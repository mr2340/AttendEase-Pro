# Project Vision: AttendEase Pro - The King of Attendance Systems

## 1. Overview
AttendEase Pro is a premium, enterprise-grade attendance management system designed to eliminate manual tracking and fraud. It features a high-end mobile-first frontend for students and a robust administrative dashboard for lecturers.

## 2. Technical Stack
- **Frontend**: HTML5, CSS3 (Vanilla/Custom Properties), JavaScript (ES6+).
- **Backend**: PHP 8.x (Modular/OOP approach).
- **Database**: MySQL (Relational schema for students, lecturers, courses, and logs).
- **Push Notifications**: Firebase Cloud Messaging (FCM).
- **Biometrics**: Web Authentication API (WebAuthn) for Fingerprint/FaceID verification.
- **Security**: Argon2 password hashing, PDO for database interactions, CSRF protection.

## 3. Core Features & User Stories

### A. Student Portal (Mobile-First)
1. **Onboarding**: High-end interactive intro screens (already mocked).
2. **Biometric Authentication**: Secure login using Fingerprint/FaceID.
3. **Attendance Marking**: Scanning dynamic QR codes generated by lecturers.
4. **FCM Notifications**: Receive instant alerts for:
   - Successful attendance marking.
   - Low attendance warnings (below 75%).
   - Upcoming class reminders.
5. **Analytics Dashboard**: Real-time progress bars and course-by-course attendance reports.

### B. Lecturer Dashboard (Web-Desktop Optimized)
1. **Class Management**: Create, edit, and schedule class sessions.
2. **QR Generator**: Generate dynamic, time-sensitive QR codes for each session.
3. **Live Attendance Tracking**: View students marking presence in real-time.
4. **Reporting**: Export attendance data to PDF/Excel.
5. **Manual Override**: Ability to mark a student present in case of technical issues.

## 4. Database Schema (Draft)
- `users`: (id, role, username, password, email, biometric_key, fcm_token)
- `courses`: (id, course_name, course_code, lecturer_id)
- `sessions`: (id, course_id, session_date, qr_code_payload, expires_at)
- `attendance`: (id, student_id, session_id, timestamp, status, verification_method)

## 6. Design Guidelines
- **Aesthetics**: Use the "Plus Jakarta Sans" font. Maintain the primary `#0066ff` blue theme.
- **Interactions**: Use GSAP or CSS transitions for "premium" feel.
- **Feedback**: Every action (scanning, logging in) must have haptic-like visual feedback.
